Up/Down Counter

Tip: Click "View Assembly Code" then "Use Code" to copy it into the editor.
Direction: UP

Interrupt Assembly Code


      

        
        
      

    

  


  

    

      
Components used in this experiment: 8051 Microcontroller, DISP0, SW0(INT0).

      
Flow of circuit: SW0(Up/Down) ⟶ P3.2(8051) ⟶ P1(8051) ⟶ DISP0.

      

      

        
        
      

    

  


  

    

      
Instructions

      
    
        
  1. Click View Circuit Diagram to see how the 8051, 7-segment display, and INT0 pin are connected in logic diagram and in block diagram.
    2. 
        
  2. Click View Assembly Code to analyse the assembly code used for this experiment.
    3. 
        
  3. Now according to your analysis write your code in the Assembly Code Editor.
    4. 
        
  4. Click Check Code to verify your program against the given code.
          
      
            
    • If correct → a success message will appear and Start Count will be enabled.
      • 
            
    • If incorrect → you’ll be asked to review and correct your program.
      • 
          
    
        
    5. 
        
  5. (Optional) You can directly copy code into editor by clicking on Use Code in View Assembly code popup.
    6. 
        
  6. After validation, click Start Count to run the simulation.  
            
      
              
    • The 7-segment display will begin counting from 0 to 9 (UP mode by default).
      • 
            
    
        
    7. 
        
  7. Click Toggle Direction (P3.2) to simulate an interrupt.
          
      
            
    • This will change the counting direction between UP and DOWN.
      • 
          
    
        
    8. 
        
  8. If you want to save your program, click Download Code. It will be stored as your_code.asm.
    9. 
        
  9. Click Reset to stop the simulation, clear the editor, and reset everything to default.
    10.
