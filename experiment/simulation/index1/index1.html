Up/Down Counter

Tip: Click "View Assembly Code" then "Use Code" to copy it into the editor.

Up/Down Assembly Code


      

        
        
      

    

  


  

    

      
Components used in this experiment: 8051 Microcontroller, DISP0, SW0, SW1.

      
Flow of circuit: SW0/SW1(Up/Down) ⟶ P2.0/P2.1(8051) ⟶ P1(8051) ⟶ DISP0.

      

      

        
        
      

    

  


  

    

      
Instructions

      
    
        
  1. Click View Circuit Diagram to see how the 8051, 7-segment display, and control pins are connected in logic diagram and in block diagram.
    2. 
        
  2. Click View Assembly Code to analyse the assembly code used for this experiment.
    3. 
        
  3. Now according to your analysis write your code in the Assembly Code Editor.
    4. 
        
  4. Click Check Code to verify your program against the given code.
          
      
            
    • If correct → a success message will appear and up/down button will be enabled.
      • 
            
    • If incorrect → you’ll be asked to review and correct your program.
      • 
          
    
        
    5. 
        
  5. (Optional) You can directly copy code into editor by clicking on Use Code in View Assembly code popup.
    6. 
        
  6. After validation, you can run the simulation. The 7-segment display will count in range of 0 to 9.
    7. 
        
  7. Click UP (P2.0) to increment the value.
    8. 
        
  8. Click DOWN (P2.1) to decrement the value.
    9. 
        
  9. If both up and down were clicked value doesn't change.
    10. 
        
  10. If you want to save your program, click Download Code. It will be stored as your_code.asm.
    11. 
        
  11. Click Reset to stop the simulation, clear the editor, and reset everything to default.
    12.
